# Publication media

Assets for `docs/blog/the-agent-needs-identity-the-model-does-not.md`.

The PNG, GIF, and MP4 were derived from a local recording of
[`obscura_jido_example`](https://github.com/hfiguera/obscura_jido_example) at
commit `e1d0f7b5fd9f1dd06df9ce724d77d55bd67f0356`. The recording uses synthetic
customer data. The OpenAI credential field remains masked, and no API key is
visible in these assets.

The GIF contains the short workflow preview. The MP4 contains the complete
silent demonstration and ends before browser chrome becomes visible. The PNG
is a 1440 by 900 frame from the completed run and is used for social previews.
