# Linux NVIDIA Article Media

The PNG files in this directory are derived from the measurements recorded in
`obscura_examples/docs/linux-nvidia-exla-validation.md`. They contain no Studio identifiers,
account details, IP addresses, or production PII.

`media-source.html` contains the reproducible 1440 by 900 layouts. To regenerate the assets,
serve this directory locally and capture each `.artboard` at its exact dimensions.

The latency graphic presents one-host LiveView smoke measurements. It must not be described as
an inference-only, capacity, or cross-hardware benchmark.
